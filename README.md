# Procedural-C-Programming-Exercises
This is a list of procedural problems with their solutions coded in C language.

## Control Flow and Functions
1. Fibonacci sequence: print first N terms
2. Check if a number is prime
3. Reverse a string in place (no extra array)
4. Convert Celsius to Fahrenheit (take an array of 10 temperatures, convert all)

## Arrays & pointers
5. Find the min, max, and average of an array of integers
6. Sort an array using bubble sort
7. Implement a function that takes a pointer to an array and its size, returns the sum
8. Merge two sorted arrays into a third sorted array

## Structs & memory
9. Define a struct Patient with name, age, heart_rate. Create an array of 5 patients, print the one with highest heart rate
10. Implement a simple stack (push/pop) using an array and a struct

## File I/O
11. Read a CSV file of numbers into an array, compute the average
12. Write a program that reads a text file and counts the frequency of each character

## Signal processing building blocks
13. Implement a moving average filter on an array of floats
14. Implement numerical differentiation (compute the difference between consecutive samples)
15. Implement a simple peak detector (find all local maxima in an array of floats)
